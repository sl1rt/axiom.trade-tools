# UI-автоматизация Axiom

Версия 0.3.7. Сбор данных выполняется через интерфейс Axiom. DOM сверялся 12–13 сентября 2026 года.

| Файл                                    | Назначение                                                           |
| --------------------------------------- | -------------------------------------------------------------------- |
| `src/ui-source.ts`                      | Trades, Fresh, модалка трейдера, Max / History / Opened ↓, прокрутка |
| `src/dom.ts`                            | Проверка полного адреса страницы и чтение ATH капитализации          |
| `src/dom-wait.ts`                       | MutationObserver, стабилизация содержимого, тайм-ауты и отмена       |
| `src/runner.ts`                         | Обход, агрегация, очередь ATH с приоритетом частых токенов           |
| `src/quote-reader.ts`                   | Малый DOM-читатель на document_start, до загрузки картинок           |
| `src/background.ts`, `src/transport.ts` | Собственные вкладки, обмен сообщениями, отмена и закрытие            |
| `src/copy-address.ts`                   | Получение полного адреса через одну отмеченную кнопку Copy           |
| `src/storage.ts`                        | Проверка сохранений и миграция текущей MC на ATH                     |
| `src/panel.ts`                          | Панель Shadow DOM, причины пропуска, таблица и экспорт               |

## DOM-контракт

Trades определяется по Age ↑, explorer-ссылке транзакции и соседней кнопке трейдера. Цвет суммы отличает покупку от продажи. Fresh — видимый лист `ri-leaf-line` или явная метка Fresh/Fresh Wallet; First Buy не исключается. Полные адреса берутся через Copy, а не из сокращённых подписей.

Модалка — ближайший общий контейнер кнопок Open in…, History и Max. Расширение сохраняет принадлежность контейнера и подпись адреса. После закрытия ждёт удаления или скрытия контейнера; ожидание работает и при отмене. При автоматическом сборе другая открытая модалка не закрывается. Явный клик по адресу в панели закрывает текущую модалку перед открытием выбранного кошелька.

History читается только после Max → History → Opened ↓. Отсутствие стрелки не подтверждает порядок. Учитывается положительная сумма или количество Bought. На Solana ссылка /meme содержит пул; полный mint берётся из имени изображения токена в этой строке. Прокрутка идёт с перекрытием, дубликаты удаляются по полному контракту.

Явное No historic positions принимается только в активной History без загрузчика, поискового фильтра и строк. Короткая непустая история требует устойчивого конца прокрутки. Ошибка распознавания не превращается в пустой результат. Причины исключения: `fresh`, `empty-history`, `no-other-purchases`.

ATH определяется внутри шапки с pair-name-tooltip, Price, Liquidity и Supply: точная видимая подпись ATH и соседняя ячейка USD. Текущая MC и document.title не служат резервным источником. Перед чтением проверяются сеть, адрес маршрута и полный адрес в explorer-ссылке. Для непрочитанной ATH сохраняются `usd: null` и причина ошибки.

## Открытие выбранного кошелька

`src/wallet-open.ts` автоматизирует штатный поиск Wallets по полному адресу. Проверка Copy до клика строки и после открытия модалки предотвращает подмену похожими сокращёнными адресами; кнопка explorer подтверждает сеть. После проверки открываются Max / History / Opened ↓. Панель показывает ход операции, поддерживает отмену и блокирует повторное открытие. При активном анализе контроллер отменяется, затем ожидается окончание его cleanup. Результаты анализа не меняются из-за ручного просмотра History.

## Очередь и сохранение

Три потребителя стартуют одновременно с обходом кошельков. Новые токены добавляются сразу. После каждой History ожидающие задания сортируются по числу уникальных учтённых кошельков; повтор одного токена внутри кошелька не даёт дополнительного приоритета. Уже активные задания не прерываются. Пустая очередь ждёт Promise до новых данных, завершения обхода или отмены.

Пауза и ошибка обхода отменяют все задания. Записи контрольных точек выполняются последовательно, чтобы старый снимок не перезаписал новые результаты. Вкладка ATH закрывается в finally и при отмене. Одной странице даётся до 25 секунд; чтение начинается до завершения загрузки изображений.

Формат 5: `historyOrder: newest`, `excludeFresh: true`, `quoteMetric: ath-market-cap`. Источник котировки: `axiom-page-ath`. Ключ: `ew.ui.scan.newest.no-fresh.<pageIdentity>`.

Совместимые результаты формата 4 сохраняют покупателей и History, но все старые котировки текущей MC удаляются; скан становится приостановленным для сбора ATH. Несовместимые ранние правила отбора не возобновляются. Миграция и отсутствие смешивания показателей проверяются модульными и браузерными тестами.

## Проверки

Синтетические фикстуры воспроизводят UI всех трёх сетей. Браузерные сценарии загружают собранный dist, проверяют выборку и отсутствие запросов расширения к API-поддоменам. В тестах используется локальный переход для вспомогательных вкладок, чтобы Playwright успел подключить маршрутизацию до навигации. Адреса Solana передаются с сохранением регистра.
