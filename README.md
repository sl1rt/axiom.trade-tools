# Axiom.trade Tools · Early Wallets 0.3.6

Расширение Chrome для поиска общих токенов у первых покупателей в Axiom.trade. Поддерживает BNB, Solana и Robinhood. Работает через интерфейс сайта: Trades, модалки трейдеров, History и страницы токенов.

## Установка

Требуется Node.js 22.12+.

```sh
npm ci
npm run build
```

Откройте `chrome://extensions`, включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите папку `dist` этого проекта. Затем обновите вкладку Axiom и откройте Early Wallets.

## Обновление

1. Пересоберите проект: `npm run build`.
2. В `chrome://extensions` нажмите ↻ у Axiom · Early Wallets.
3. Обновите вкладку Axiom. В панели должна быть версия **0.3.6** и колонка **ATH MC · USD**.
4. После 0.3.5 нажмите **Продолжить / повторить**: собранные History сохраняются, прежняя текущая капитализация удаляется, ATH собирается заново. Для 0.3.4 и более ранних версий нужен новый анализ из-за изменения правил отбора.

## Как считается результат

По умолчанию выбираются **50 кошельков / 5 других токенов**.

1. **All → Age ↑**: первые уникальные кошельки из покупок. Продажи и повторные покупки одного кошелька не увеличивают выборку.
2. Полный адрес читается через кнопку Copy в модалке трейдера. Кошельки с меткой **Fresh** (лист) исключаются без чтения History. Значок First Buy не означает Fresh.
3. **Max → History → Opened ↓**: пять самых свежих уникальных других токенов с покупками. Положительной должна быть сумма или количество в Bought. Исходный контракт, строки без покупок и дубликаты пропускаются; при необходимости список прокручивается дальше.
4. При 1–4 подходящих токенах учитываются доступные. Пустая History пропускается сразу. Если после просмотра истории нет покупок других токенов, кошелёк тоже исключается. Причины и полные адреса показаны в панели. Пропущенные кошельки остаются среди исходных 50 и не заменяются более поздними.
5. Токены группируются по сети и полному адресу. Счётчик — число уникальных учтённых кошельков; процент рассчитывается среди учтённых кошельков. Одинаковые названия разных контрактов не объединяются.

История читается в сети исходного токена. На Solana страница `/meme/<pool>` ограничивает исходную выборку открытым пулом. Результат отражает совпадения только в выбранных токенах каждой History.

## ATH капитализации

**ATH MC · USD** — значение ячейки **ATH** в шапке токена Axiom. Текущая MC, цена, ликвидность и название вкладки не используются вместо ATH. Если ячейка не загрузилась, показывается «Нет данных», без подстановки другого показателя.

Каждый новый токен сразу попадает в очередь. До трёх неактивных вкладок читаются параллельно обходу трейдеров. Ожидающие токены с наибольшим числом кошельков получают приоритет; порядок пересчитывается после каждой History. Уже начатые загрузки завершаются. Анализ заканчивается после обработки кошельков и всей очереди ATH.

Axiom округляет значение. Время проверки сохраняется в `fetchedAt`; это снимок показанного ATH, без постоянного автообновления.

## Управление и ограничения

- Во время анализа оставьте вкладку открытой и не меняйте таблицу, сортировку или модалку.
- **Приостановить** останавливает обход и закрывает созданные вкладки ATH. **Продолжить / повторить** использует сохранённые History и повторяет отсутствующие/устаревшие ATH.
- Клик по числу кошельков раскрывает адреса. Есть фильтр «От двух кошельков» и экспорт JSON.
- Ошибка интерфейса не считается пустой историей. Исчезновение модалки или нераспознанная колонка приостанавливают анализ.
- Полнота зависит от данных, загруженных интерфейсом. Недостаточная выборка покупателей помечается в панели.
- Метки Age/Opened округлены; исходный текст сохраняется, время вычисляется приблизительно. Порядок берётся из таблицы.
- Не запускайте один токен одновременно в нескольких вкладках: у них общий ключ локального сохранения.

## Доступ

Нет сервера, телеметрии и торговых действий. Расширение не отправляет прямых HTTP-запросов к API Axiom и не читает cookies, ключи или внутреннее состояние приложения. Сетевые запросы самого сайта при кликах остаются видны в DevTools.

Разрешения: `storage`, `scripting`, доступ только к `https://axiom.trade/*`. Для получения публичного адреса расширение временно перехватывает текст от отмеченной кнопки Copy, проверяет адрес по видимой подписи и восстанавливает метод. Буфер обмена пользователя не читается и не изменяется.

## Разработка и проверки

```sh
npm run check
npm run build
npx playwright install chromium
npm run test:browser
```

Браузерные тесты загружают реальное MV3-расширение на синтетической странице. Они проверяют выборку, Fresh, Bought, сортировку History, ATH, миграцию сохранений, параллельную очередь, паузу и восстановление. Это проверка адаптера; изменение разметки Axiom может потребовать его обновления.
